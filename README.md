# Stremio Live Stream Manager

One live HLS stream → Stremio. The URL is stored in memory + `data.json`, changeable from `/admin` with no redeploy. The video is never proxied; Stremio gets the original URL.

## Environment variables
| Name | Required | Purpose |
|---|---|---|
| `PORT` | no | Set by Render. Default 7860 (Hugging Face). |
| `STREAM_URL` | recommended | Initial/fallback HLS URL. Used when `data.json` doesn't exist. |
| `ADMIN_PASSWORD` | yes, for admin | Protects `/admin` and `/api/*`. If unset, admin is disabled. Username can be anything. |
| `SOURCE_MODE` | no | `manual` (default) or `automatic`. |
| `SOURCE_URL` | automatic only | Public page/API that exposes the `.m3u8` URL. |
| `SOURCE_MATCH` | optional | Substring to pick one URL when the source lists several. |
| `REFRESH_INTERVAL` | no | Seconds between checks in automatic mode. Default 300, minimum 10. |
| `DATA_FILE` | no | Path for the JSON store. Default `data.json`. |

Hugging Face: add `STREAM_URL` and `ADMIN_PASSWORD` as **Secrets**; the rest as **Variables** (Settings → Variables and secrets).
Render: Service → Environment → Add Environment Variable.

## Local test
```bash
npm install          # no dependencies; harmless
STREAM_URL='https://example.com/live.m3u8?token=1&x=2' ADMIN_PASSWORD=pick-one PORT=7860 npm start
```
- http://localhost:7860/manifest.json
- http://localhost:7860/admin (any username, your ADMIN_PASSWORD)
```bash
curl localhost:7860/stream/tv/live1.json
curl -u admin:pick-one localhost:7860/api/status
```

## Deploy
**Hugging Face:** New Space → SDK Docker → **Public** → upload these files (Dockerfile at repo root; keep this README's header) → add variables/secrets.
**Render:** push to GitHub → New Web Service → Runtime Docker → add env vars.

## Install in Stremio
Paste into the addon search box: `https://<your-deployed-domain>/manifest.json`
(HF domain: `https://<user>-<space>.hf.space`, Render: `https://<service>.onrender.com`). The channel appears under TV → Live Stream.

## Manual mode
Open `/admin`, paste the new `.m3u8`, Test Stream, Save Stream. Stremio uses it on the next request. The URL is stored exactly as pasted.

## Automatic mode
`SOURCE_MODE=automatic` + `SOURCE_URL`. Every `REFRESH_INTERVAL` seconds the server fetches that page (10s timeout, 2 MB cap), finds `.m3u8` URLs in the public HTML/JSON, and updates the active URL only if it changed. It un-escapes JSON/HTML encoding of the *page* (`\/`, `\u0026`, `&amp;`) to recover the URL; the URL itself isn't otherwise altered. Zero matches or several matches without `SOURCE_MATCH` count as a failure.
It only reads what the page serves publicly. If the stream URL needs a login, an app session, or is generated by a private API, automatic mode can't work: use manual.
On failure it keeps the previous URL, logs a short error, and shows "Source error" in `/admin`. In automatic mode a manual save is overwritten at the next refresh if the source reports a different URL.

## When a signed URL expires
Stremio gets the expired URL and playback fails (typically HTTP 403/410). Nothing in the addon crashes. Manual mode: use Test Stream in `/admin`, paste a fresh URL, Save. Automatic mode: the next refresh picks up the new one if the source publishes it.

## Persistence caveat
`data.json` lives on the container's filesystem. Hugging Face free Spaces and Render free web services are ephemeral: a restart/redeploy deletes it and the app falls back to `STREAM_URL`. Conversely, `data.json` wins over `STREAM_URL` while it exists, so on a persistent disk changing `STREAM_URL` alone has no effect; use `/admin`. To persist elsewhere, replace `load`/`save` in `src/store.js`.

## Security notes
- `/stream/tv/live1.json` is public (Stremio can't authenticate), so anyone with your addon URL can read the stream URL. Keep it private.
- Admin uses HTTP Basic auth over the platform's HTTPS; the password never reaches page JavaScript. Failed logins are rate-limited (10/min per IP).
- `/admin` shows only a masked URL. Test Stream fetches the first 2 KB of the playlist from the server; no video passes through.
